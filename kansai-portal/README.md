# 🌸 日本關西旅遊互助群 全平台影音下載導航神器 (獨立版)

這是一套完全獨立、零伺服器後端流量負擔的「社群影音下載導航聚合站」。

## ✨ 特色與優勢
1. **零伺服器流量負擔**：不需經由雲端主機中繼下載影片，徹底擺脫流量超標、限制與費用問題。
2. **全平台覆蓋**：精選 Instagram、YouTube (4K/MP3)、TikTok/抖音、Threads、Facebook、小紅書、X (Twitter)、Bilibili 等 10 大平台。
3. **首選推薦 Cobalt / SnapAny**：精選全球最乾淨無毒、零廣告的頂級下載神站。
4. **極速響應與現代設計**：支援即時平台搜尋、動態展開推薦站點、自適應手機與電腦螢幕。

## 🚀 使用方式
- 只要雙擊開啟 `index.html` 即可直接在瀏覽器開啟使用。
- 也可隨時獨立上傳部署至 GitHub Pages、Vercel、Netlify 或 Zeabur 等免費靜態網站平台。
